## Descripción del Repositorio

Este repositorio contiene las prácticas correspondientes a la materia de Aplicaciones Web.

En esta primera práctica (`practica-01-entorno`), se llevó a cabo la instalación, configuración y verificación del entorno de desarrollo web completo, incluyendo:

- Editor de código (Visual Studio Code) con sus extensiones.
- Sistema de control de versiones (Git) y vinculación con GitHub.
- Entorno de ejecución de JavaScript (Node.js) instalado mediante el gestor de versiones `nvm`.
- Creación de una página web básica utilizando HTML, CSS y JavaScript, probada con Live Server y DevTools.
